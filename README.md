# Hotel Reservation System

A simple Hotel Reservation System developed using Python and Streamlit.

## Features

- View available hotel rooms
- Room categorization:
  - Standard
  - Deluxe
  - Suite
- Book hotel rooms
- Cancel reservations
- Payment simulation
- View booking details
- Data storage using JSON File I/O
- Object-Oriented Programming implementation

---

## Technologies Used

- Python
- Streamlit
- JSON File Storage
